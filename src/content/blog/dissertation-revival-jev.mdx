[Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) is a quick classifier by TypeSafe. I wanted to see it in action after seeing it play Doom, turns out it's actually pretty decent for a generalized model, though not close to models trained specifically on the game.

## What's Jev?

<Fig title="Each pass, and what it outputs">
  <Decide tokens={["{\"", "move", "\":", " \"", "left", "\"}"]} choices={[{ name: "left", p: 42 }, { name: "right", p: 36 }, { name: "shoot", p: 22 }]} />
</Fig>

An LLM runs once for every token it writes, so even a short structured answer like `{"move": "left"}` takes about six passes, and it gives you the move, not a probability for every choice. Jev runs once and gives every choice a probability, in about 200 ms.

## How do we ask it?

<Fig title="One move: what we send, and what comes back">
<p class="fig__k">we send (click a long line to open it)</p>
<Json value={{
  "model": "jev-latest",
  "state": "Grid 30 columns by 11 rows, (column,row), row 0 at the top. Your ship: (14,10), it can only move left or right. Your shot in the air: none. Aliens (6), nearest first: (15,0), (18,0), (8,0), (21,0), (5,0), (2,0). Bombs falling, nearest first: (12,5). Columns with a shield: 0, 1, 2, 3, 4, 5, 6, 7, 13, 15, 17, 19, 23, 24, 25, 26, 27. Bombs within 2 columns of your ship: column 12 (-2 from you), 5 rows above.",
  "questions": {
    "move": {
      "type": "choice",
      "instructions": "You are playing Space Invaders. Aliens move sideways and drop bombs straight down. Win by destroying every alien, lose if a bomb or an alien touches your ship. Shots that hit a shield are wasted and only one of your shots can be in the air at a time. Pick the best move right now.",
      "criteria": {
        "shoot": "fire a shot straight up from your ship's column",
        "left": "move two columns left",
        "right": "move two columns right"
      }
    }
  }
}} />
<p class="fig__k">Jev sends back</p>
<Json value={{
  "model": "jev-1.14.0",
  "answers": { "move": { "choice": "left", "probabilities": { "left": 0.42, "right": 0.36, "shoot": 0.22 } } }
}} />
</Fig>

Unlike my learning agents, Jev uses a structured state instead. The above is the input call to it and we get back a structured reply with probabilities. We just select the max option each time.[^json]

## One line of the prompt changed a lot

<Fig title="The line we added to the state">

Jev is very prompt dependent. Every bomb's position was already in the state, but Jev kept walking into them, so we added one line working out which bombs are close to the ship. It won 22 of the same 26 games, and 61 of the next 78 it hadn't seen.

## Closing remarks

It's kinda mid, at least for this use-case. It's cool that a generalized pre-trained model can do relatively well and it's cheap per call but this game application specifically it wasn't that great.

[^json]: I also tried sending the state as JSON, which TypeSafe's docs allow, and it did no better: 75% of the same 104 games and 41 points.
[^one]: One set of 104 games per setup, and I picked the bomb line after seeing the first 26. Every run is in [the results](https://github.com/ColinCee/GVGAI-Dissertation/blob/master/2026-revival/RESULTS.md#jev-a-decision-model-with-no-training-aliens-26-oct-2026).
[^test]: Jev played one set of 104 games, so a gap counts as real only when it's outside holding shoot's range over its 5 sets (36 to 38 points, 80% to 85% wins).

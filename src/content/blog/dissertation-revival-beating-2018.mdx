In [part 1](/blog/dissertation-revival-speed/) Claude got my 2018 code training 65× faster. With runs that cheap, I wanted to see if today's methods could beat what I built as an undergrad.

My 2018 agent wins 81% of Aliens games and scores 50 points a game. The best agent we got to wins 299 games out of 300 and scores 83. It even beats a tree search that plans every move, and no learning agent came close to that before. All the code and results are in [my dissertation repo](https://github.com/ColinCee/GVGAI-Dissertation).

## How did we beat it?

Each row adds one change to the row above it:

- **An extra 4M frames** of training, 5M in total.
- **Win + points ÷ 10**, a new reward: +1 for a win, −1 for a loss, plus a tenth of the points.
- **The IMPALA network**, a bigger one.
- **A move every 2 frames** instead of every 4.

Winning comes first, and points only break ties between agents that win. As far as I know, that's how the GVGAI competition ranks them too. So the bars are games won, and points sit next to them.

More practice did most of the work on wins, and the new reward took it to almost every game. After that, moving more often didn't change wins, but it added 20 points.

At each step I kept whatever won, wins first and then points, but with only 3 runs each a gap only counts when the runs don't overlap, otherwise it's a tie and I keep the simpler or cheaper one.[^runs3]

## Do newer methods beat it?

I tried three, each with the same 1M frames my agent got:

- **[DQN](https://www.nature.com/articles/nature14236):** DeepMind's 2015 Atari method. It scores each move from the screen and plays the best one. My agent is DQN plus 2 tricks.
- **[Rainbow](https://arxiv.org/abs/1710.02298):** DQN plus 6 tricks, including my 2.[^rainbow]
- **[PPO](https://arxiv.org/abs/1707.06347):** a different kind of learner that picks moves directly.

## Which reward works best?

The reward is what the agent gets told is good. I tried mixes of three:

- **Points:** the game score.
- **Win:** +1 for a win, −1 for a loss.
- **2018 (mine):** win, plus −0.5 on every move of a lost game.

## How often should it move?

This is the one I never thought about in 2018. The agent holds each move for 4 frames, which is DeepMind's Atari setup. I suspected that makes some shots and positions impossible to reach. A tree search called MCTS picks a move every frame, and it scores 78 with no training at all.

Wins hardly move since they were already near the top, so points are where it shows:

- **Every 2 frames** scored 83 and won 299 of 300 games, in about 53 minutes a run.
- **Every frame** scored 82 and won all 300, but took about 3 hours a run.

That's a tie on points, so I kept every 2 frames since it's over 3 times quicker to train, and that's the last row of the chart at the top. Both beat MCTS's 78 too, but it does still lose that 1 game in 300.[^moves]

## Why does it still lose 1 game in 300?

I replayed the lost games. As far as I can tell, every loss is the same thing: a bomb lands on the ship while it sits still and shoots.

I think the reward is to blame:

- **Points add up.** Each one is worth +0.1, and a game has about 40 kills. That's roughly +4.
- **A death only costs −1.** So a risk for more points is nearly free.
- **More weight on points, more deaths.** With a move every 4 frames, that's 0 deaths in 300 games at points ÷ 20, 4 at ÷ 10 and 7 at ÷ 5.

The fix should be a loss that costs more than the points can earn, like ±10 for the result. That's a follow-up for another day.

## What did I learn?

- **Question the settings you copied.** Holding each move for 4 frames came from Atari, and here it cost about 20 points.
- **Check the dumbest baseline first.** Holding one button doesn't need any training, and I never tried it.
- **Run everything more than once.** My two 2018 runs of the same agent were 10 to 17 points apart.
- **Claude wrote all of the code, but it liked to stop early.** I pushed back six times in about 2½ hours.[^log]
- **I was the least informed person on my own dissertation.** About a third of my messages were me learning things like PPO and IMPALA.

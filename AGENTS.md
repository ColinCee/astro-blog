# Agent notes for this blog

Checks: `pnpm install --frozen-lockfile && pnpm exec playwright install chromium && pnpm check` (works from a fresh clone with no sudo or Cloudflare login; `pnpm check` runs everything CI runs: typecheck, Biome, post prose wrapped at 100 columns (`pnpm format` wraps it; figures stay as written), build, Wrangler dry run, Playwright tests and speed budgets)

- **Everything about a post lives in its frontmatter.** The home page, the blog index and the post page all read the same four fields: `title` (one short title, used everywhere), `stat` (the one headline result), `statLabel` (what the stat measures) and `pubDate`. One field per fact: no subtitle or extra figures restating the stat (dropped Oct 2026 as noise). Never add a per-post table to a page; a new post must show up everywhere with no other file changed.
- **Tooling is the latest stable, modern and fast:** pnpm, Biome, the latest TypeScript and Astro, current Node LTS. Scripts are TypeScript, which Node runs directly; no new `.js` or `.mjs`. When something can be replaced by a faster or newer standard tool, do it.
- **Posts about work stay high level.** This repo is public and work code is private: no repo, product, package, file or colleague names, and no work code or config. Counts, timings and the general idea are fine. That applies to plan and draft files here too.
- **One accent per glance.** Colour sprinkled everywhere makes a page hard to read; the rule is DESIGN.md's Accent Points Rule.
- **One dev server, on port 4331, for the checkout being worked on.** When switching branch or worktree, stop it and start it on the new one. Before/after preview servers for PR captures (other ports) run only while capturing, then stop. Restart it after a long run of edits; hot reload grows its memory past 10 GB.
- **Pages keep to their speed budgets.** `pnpm speed` (also in `pnpm check` and CI) fails a page that gets heavier or slower than its budget in `tests/speed.spec.ts`; how and why are in `docs/page-speed.md`. Make the change fit; raise a budget only with the reason in that PR.
- **Cloudflare's bot detection stays on.** Its injected script costs the Lighthouse best-practices score about 20 points; that score doesn't matter, so don't chase it.
- **During the redesign, `src/pages/design.astro` (`/design/` on the dev server, not built) is the design system** (colours from `docs/redesign/comps/tokens.mts`, which writes `src/styles/scales.css`). Colin wants it kept current: change it in the same commit as any design decision, and read it and `docs/design-rejected.md` before proposing one. An idea he drops goes in that file the same turn.
- **Writing or reviewing a post:** follow `.claude/skills/writing-posts/SKILL.md` (story, his voice, numbers, figures, shipping). Figure components and tokens are in `DESIGN.md`.
- **A PR shows what it changes**, so Colin can scan it before merging: screenshots or a video when a page looks or moves differently, a chart when only numbers change (speed, size), nothing when neither does. Follow `.claude/skills/pr-visuals/SKILL.md`.
